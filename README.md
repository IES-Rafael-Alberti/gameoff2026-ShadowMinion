## Cómo ejecutar el proyecto

1. Clona este repositorio:
   ```bash
   git clone https://github.com/IES-Rafael-Alberti/gameoff2026-shadow-minions.git
   ```
2. Abre Godot.
3. Selecciona **Importar** y elige el archivo `project.godot` de la carpeta clonada.
4. Ejecuta el proyecto con **F6** para la escena actual o **F5** para el proyecto principal.
